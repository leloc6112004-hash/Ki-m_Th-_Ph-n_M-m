User Registration Flow

Add a user registration page connected to the login page.

Navigation Interaction:
When the user clicks the "Đăng ký" button on the login panel, the system navigates to the Registration Page.

Registration Page Layout:

The page keeps the same modern healthcare design style used in the login and forgot password pages.

Style:

* Minimalist medical UI
* White, light blue, and soft green color palette
* Rounded buttons and input fields
* Soft shadows
* Clean modern typography
* Responsive layout

The page can use the same full-screen healthcare themed background image.

Inside the page place a centered frame or card containing the registration form.

Registration Form Content:

Title (H1):
Đăng ký

Input Field 1:
Label: Username

Placeholder text:
Nhập số điện thoại hoặc email

Input Field 2:
Label: Password

Placeholder text:
Nhập mật khẩu

Input Field 3:
Label (English):
Confirm Password

Placeholder text:
Nhập lại mật khẩu

Buttons Section:

Below the input fields place a primary button:

Button text:
Đăng ký tài khoản

OTP Verification After Registration:

After the user clicks the "Đăng ký tài khoản" button, the system should navigate to an OTP verification screen similar to the OTP verification used in the Forgot Password process.

OTP Verification Layout:

Title (H1):
Xác thực OTP

Description text:
Vui lòng nhập mã OTP đã được gửi đến email hoặc số điện thoại của bạn.

OTP Input:
Display multiple OTP input boxes (4–6 digits).

Below the OTP input field add a clickable text link:

Gửi lại mã OTP

Below that add a button:

Xác nhận

OTP Verification Logic:

If the OTP is correct:

* Display a success message: "Đăng ký thành công"
* Automatically navigate to the Login Page.

If the OTP is incorrect:

* Display an error message: "Nhập sai mã OTP, vui lòng thử lại."

Design Requirements:

* Maintain consistent UI with login and forgot password pages
* Use rounded components and soft shadows
* Ensure clean spacing and readability
* Keep the layout responsive across desktop, tablet, and mobile screens
