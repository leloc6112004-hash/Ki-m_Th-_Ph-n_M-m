Design a modern, clean, and professional healthcare website login page connected from the homepage. Style: * Minimalist medical style * Primary colors: white, light blue, and soft green * Friendly, trustworthy, and modern look * Rounded buttons, soft shadows, clean typography * Clean spacing and modern UI components Navigation Interaction: When the user clicks the "Đăng nhập" button from the homepage navigation bar, the system should navigate to the Login Page. Login Page Layout: The page uses a full-screen healthcare themed background image (hospital, doctor, or medical illustration). At the top-right corner of the screen there is a hamburger menu icon (three horizontal lines). The hamburger menu controls a login panel that appears from the right side of the screen. Default State: When the user first enters the login page: * The hamburger menu is already active * The login panel is visible * The panel occupies about 50% of the screen width on the right side * The left side of the page displays the healthcare background image Login Panel Design: The login form is placed inside a frame or card. Panel style: * White background * Rounded corners * Soft shadow * Clean padding * Modern medical UI style Login Form Content: Title (H1): Đăng nhập Input Field 1: Label: Username Placeholder text: Nhập số điện thoại hoặc email Input Field 2: Label: Password Placeholder text: Nhập mật khẩu Forgot Password Section: Below the password field there is a clickable text link: Quên mật khẩu? Buttons Section: Below the "Quên mật khẩu" text there are two buttons. Primary Button: Đăng nhập Secondary Button: Đăng ký Button Style: * Rounded corners * Soft shadow * Primary color for the login button * Outline style for the register button Hamburger Menu Interaction: When the login panel is currently visible and the user clicks the hamburger icon, the login panel should slide out and close. When the login panel is hidden and the user clicks the hamburger icon, the login panel should slide in from the right side. Animation: Use a smooth slide animation from right to left. Animation duration: 300ms Use a smooth easing transition. Responsive Design: * The layout should be responsive * On smaller screens the login panel can expand to full screen * Maintain clean spacing and readability across devices
