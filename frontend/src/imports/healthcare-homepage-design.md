Design a modern, clean, and professional healthcare website homepage UI.

Style:
- Minimalist medical style
- Primary colors: white, light blue, and soft green
- Friendly, trustworthy, and modern look
- Rounded buttons, soft shadows, clean typography

Layout Structure:

1. Header / Navigation Bar
- Logo on the left
- On the right: two primary buttons
  - "Đăng nhập"
  - "Đăng ký"
- Sticky navigation bar

2. Hero Section
- Large medical themed illustration or doctor image
- Main headline: "Đặt lịch khám nhanh chóng và tiện lợi"
- Short description about online medical appointment booking
- Primary CTA button: "Đặt lịch hẹn ngay"
- Secondary CTA: "Tìm bác sĩ"

3. About Us Section (Về Chúng Tôi)
- Short introduction about the clinic/hospital
- Mission, vision, and commitment to patient care
- Icons or small illustrations

4. Advantages Section (Ưu điểm của hệ thống)
Display 4–5 feature cards with icons:
- Đặt lịch hẹn nhanh chóng
- Không phải chờ đợi
- Hệ thống minh bạch và công bằng
- Bác sĩ uy tín
- Quản lý lịch khám dễ dàng

5. Doctors Team Section (Đội ngũ bác sĩ)
- Grid layout with doctor cards
- Each card includes:
  - Doctor photo
  - Name
  - Specialty
  - Experience
  - Button "Đặt lịch"

6. Specialties Section (Chuyên khoa)
- Display categories like:
  - Tim mạch
  - Da liễu
  - Nhi khoa
  - Tai mũi họng
  - Nội tổng quát
- Use icons for each specialty

7. Appointment Section
- Highlight the appointment booking feature
- Big call-to-action button: "Đặt lịch khám ngay"

8. Footer
Include:
- Clinic address
- Hotline number
- List of clinic branches
- Email contact
- Social media icons
- Company name: Ecommer
- Year established
- Copyright

Design Requirements:
- Responsive web layout
- Clean spacing
- Medical themed icons
- Modern UI components
- Use card layouts for doctors and features
